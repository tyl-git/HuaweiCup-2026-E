# 问题二和问题三：附件二输入与评价协议（v1.0）

## 1. 数据边界

训练、验证和常规测试统一使用题目提供的 `aligned_50.pkl`，保持原有 `train / valid / test` 划分；附件三和附件四只选择各自的**对齐版本**做专项推理。不能在训练时把 `unaligned_50.pkl`、问题一自提特征或专项无标签样本混入这条输入链。问题一的维度为 768/25/49，附件二的官方维度为 768/74/35，含义和处理流程不同。

附件二的 50 表示固定序列位置数，不是每条样本都有 50 个有效词，也不是 50 个等长视频时间窗。目标接口为 `text:(50,768)`、`audio:(50,74)`、`vision:(50,35)`，各字段相同样本索引对应同一条片段。`text_bert:(3,50)` 是词元编号、注意力掩码和分段编号，用于定位文本有效位置或重新编码，不是第四模态。

**专项接口存在一项差别：附件三没有 `text`，仅提供 `text_bert`、`audio` 和 `vision`。** 后续统一采用本地固定版本 `google-bert/bert-base-uncased`，将各集合的官方 `text_bert` 编码为最后层 768 维向量；模型冻结、`eval()`、float32、无微调，缓存编码结果并保存输入/模型指纹。这样训练与附件三使用相同文本定义。不能在附件三用全零文本代替缺失的 `text` 字段，也不能用 ASR 或其他转写替换官方 token。**train 3,395 条与 valid 728 条已全部重新编码**；与原包预计算 `text` 的内容位置相比，最大绝对差分别为约 5.43e-4、2.68e-4，平均绝对差约 6.33e-7、6.30e-7。它们支持数值兼容性，但不证明原特征的全部生成细节。缓存只读复核通过；test 和附件三、四尚未执行编码或情感推理。见[文本编码缓存报告](../../03_Results/e/question-two/2026-09-24_q2-text-cache_v1.0.md)。

附件三最外层是 `test` 且含批次维 1，`text_bert` 存为 float32；附件四是单样本平面字典，音视频为 float64。加载器应先检查 token 值确为整数，再转换为 int64，去除/补上批次维，并将连续特征统一为 float32。字段层级与 dtype 差异不能靠盲目 reshape 掩盖。

标签采用题目给定原值，不擅自重标注。三分类为 0=Negative、1=Neutral、2=Positive；连续强度为 [-3,3]，0 只属于中性。分类与回归分别输出，不用回归值的简单符号规则代替三分类头，因为正好预测到 0 的事件概率、类别不均衡和阈值选择都会影响中性类。原始 `id`、文本、标签与 `label.xlsx` 的核验结果见附件二审计报告。

## 2. 有效位置与缺失表示

文本填充位置并不保证是全零向量。序列位置掩码须从 `text_bert` 的 attention mask 读取，不能由 `text` 的零值判断。建模的内容位置进一步排除 BERT 特殊词元 `[CLS]=101` 和 `[SEP]=102`；附件二及两套对齐专项接口均已核实为前缀有效、其余为 padding。注意力层编码时保留 `[CLS]`/`[SEP]`；内容池化和局部缺失统计时排除它们。原始有效长度、内容长度及每种模态的可观测位置数分别统计，不互相替代。

音频/视觉一整行全零只能先记为“该位置没有非零观测”，并与内容位置掩码共同使用。附件三题目明确用连续全零区间模拟局部模态缺失；但附件二中的全零行也可能来自原始填充或原处理流程，不能自动宣称它是现实遮挡或转写失败。统一输入返回三种特征、内容位置掩码、逐模态观测掩码、原 `id` 和标签；保留原数据中的零值，不在原 PKL 中改写。

训练批次为固定 50 个位置，所有池化、注意力和损失计算均使用上述掩码。缺失位置若做标准化，必须保持零占位，并把独立掩码交给模型；不能让标准化把缺失零变成看似真实的非零特征。全视觉零样本也保留，通过掩码参与可用模态的预测。

## 3. 预处理与划分纪律

数值检查包括形状、dtype、有限值、有效长度、标签范围、跨集 ID 与视频 ID 重合、`label.xlsx` 对照以及全零段的分布。只有训练集的**有效且有观测的位置**可用于拟合每个模态的均值和标准差；验证/测试/专项仅应用训练统计量。方差为零的维度使用安全下界，不能产生 NaN。所有统计量、阈值和配置连同随机种子保存。

不得通过查看验证/测试或附件三、四的预测效果来反向修改标签、样本顺序、标准化统计量或缺失标记。训练集用于参数更新；验证集用于模型结构、超参数、融合权重、早停和分类阈值；官方测试集在方案固定后只进行最终常规评估。附件三、四无标签，只在冻结模型后推理。

## 4. 基线与评价口径

第一组基线依次建立训练集多数类/均值常数预测、文本单模态、音频单模态、视觉单模态、简单三模态融合。它们共用同一划分、掩码、标准化和评价脚本；再与局部缺失鲁棒模型比较。单模态缺失时不可把全零向量当作测量值；空观测样本保留，并按事先定义的可用输入/先验分支预测。

极性报告三分类 Accuracy 与 macro-F1，并同时报告各类 Precision/Recall/F1 和混淆矩阵，以展示中性类与类别不均衡。强度报告 MAE 与 Pearson r；若某个评价子集真值或预测为常数、Pearson 不可定义，则明确记为 `undefined` 并报告样本数，不填 0。主评价同时给出完整输入和人工构造局部缺失输入的结果，所有指标都注明 split 与有效样本数。

缺失实验在**有真实内容且原先有非零观测**的位置构造连续区间，保持原样本数与标签不变。按缺失模态（文本/音频/视觉及必要的组合）、区间位置（起始/中间/末尾）、缺失比例或长度分别报告，并固定随机种子和同一批被遮挡索引，使模型间比较成对。实际掩蔽比例以被遮挡的原可观测位置数为分母，不能用固定 50 充当分母。训练阶段的缺失增强只施加在训练集；验证缺失集用于选模型，测试缺失集仅用于冻结后的评估。

## 5. 实现验收与下一步

1. 附件二全量审计及专项结构核验已完成，审计报告记录特殊词元、全零行、标签、重复样本及截断统计。
2. 只读统一加载器已完成；三个官方 split 和 50 个专项文件通过形状、掩码、标签、有限值与跨官方划分泄漏断言；9 项异常边界测试通过。预计算文本仅以 `reference_text` 返回，不能误作统一文本输入。
3. train/valid 统一 BERT 缓存已生成；只由 train 拟合的三模态标准化参数已保存并复算一致，valid 只应用训练参数。标准化后缺失及填充保持全零，观测掩码独立保留。详见[标准化验收](../../03_Results/e/question-two/2026-09-24_q2-normalization_v1.0.md)。
4. 统一评价脚本、常数参考及 text/audio/vision/fusion 基线各三个种子已完成，12 次运行通过独立审计。普通融合模型已进行验证集 18 个局部缺失条件的评估；完整输入重载预测与原记录核对一致。下一阶段准备局部连续缺失增强与动态融合的消融实验，由用户手动启动所有训练；仅在模型冻结后生成附件三、四专项预测文件。

缺失文本实验目前在冻结 BERT 输出的特征行上施加掩码。其余词元向量已编码完整句子上下文，因此这种特征缺失不等价于先删除原文再编码；论文须明确模拟层级，不将它写作真实转写缺失或因果解释。原始非零观测不足一整段时，目标 20%/40% 按样本向上取整，实际比例单独记录。

本协议是后续建模的统一约定。第一轮基线训练及普通融合缺失评估已完成，增强训练和专项推理尚未完成。实现入口、复跑命令与结果见[问题二成果索引](../../03_Results/e/question-two/2026-09-24_q2_results-index_v1.0.md)。
